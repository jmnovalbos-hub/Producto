# Grupo Northius · Entorno de formación

Entorno de formación comercial del Grupo Northius (Tokio School, Campus Training, Unisport, Nubika, Flou, 35MM, CEMP, MINT y CEAC).

Es un único archivo `index.html` autocontenido: no necesita servidor ni instalación.

## Publicar con GitHub Pages

1. Crea un repositorio (recomendado: **privado**).
2. Sube `index.html`, `.nojekyll` y este `README.md` a la raíz.
3. En el repositorio: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, rama `main`, carpeta `/ (root)`.
4. La web quedará en `https://<usuario>.github.io/<repositorio>/`.

## Importante

El contenido es material interno (guiones de venta, argumentarios, precios y perfiles de cliente).
En las cuentas gratuitas, una web de GitHub Pages es pública aunque el repositorio sea privado.
Para restringir el acceso a la organización hace falta GitHub Enterprise Cloud (Pages con control de acceso).
